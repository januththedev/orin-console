Getting started

Orin Console gives you a real Linux terminal in your browser. Each session boots an isolated cloud sandbox with a genuine shell — not an emulation. Anything you can do over SSH, you can do here.

1 · Sign in

Open console.orinai.org and sign in with your Orin account — the same email and password you use for Orin Chat. New here? Create an account on the same card; it works across Chat, Console and Router.

2 · Boot a session

  1. Click Launch Console, then Boot sandbox.
  2. Optionally set terminal size, ports to expose (e.g. 3000, 5173), and env vars (NAME=value per line).
  3. A fresh sandbox boots in seconds and the terminal opens.

3 · Use the terminal

Type as normal. Useful shortcuts: Ctrl+C interrupt, Ctrl+D end input, Ctrl+L clear screen, ↑ ↓ command history. The ⧉ button copies your selection; 📋 pastes from the clipboard (handy on mobile).
