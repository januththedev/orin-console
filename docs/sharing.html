Sharing

Open the 🔗 Share dialog in any session to create a link. Guests need no account — the link carries a random 256-bit token that is shown once, stored only as a hash, and revocable at any time.

View only

Guests watch the terminal live and replay history. They cannot type. Safe to post anywhere — use it for demos, interviews and debugging walkthroughs.

Terminal access

Guests get a fully interactive shell in your sandbox: they can run commands, read your files and use the network. Only share terminal links privately, with people you trust, and revoke them when done.

Rules every link follows

  • Links die with the session (8h max).
  • Env vars and secrets are never shared — guests see masked output only.
  • Creating or revoking a link is recorded in session history.
